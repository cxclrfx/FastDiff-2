# Licensing and delivery

FastDiff V2 is a proprietary reconciliation product designed for local binary delivery. This repository provides the product documentation and synthetic examples. The implementation is maintained privately.

## Current release status

The current release provides documentation; production binary availability is tracked in the [release notes](../RELEASE_NOTES.md). Commercial terms, the applicable executable license and any support entitlement must accompany future binary delivery. Commercial purchase, production activation files and a final binary EULA are not offered by this documentation release.

The [repository notice](../LICENSE.txt) governs this package and grants no commercial executable license. Previously distributed FastDiff materials retain their own licenses.

Signing keys, development licenses and customer license files remain private and are excluded from this repository.
